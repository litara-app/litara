# Sign-in backgrounds

`marble.webp` (marbled paper), `library.webp` (library at night) and `shelves.webp` (bookshelves) were generated by the repository owner with ChatGPT and supplied on 2026-11-19. The owner states they are free to use. They are used for the sign-in backdrop and the inside of the book cover; the build neither generates nor fetches them.
