# M1 slice 3: native PDF and comic reading on the integrated server

Observed 2026-11-17 on `emulator-5554` (Pixel_9_Pro, Android 17) with the `full` debug APK against the disposable stack from
`scripts/t007/stack.py` (merged T001–T006 + this branch). Fixtures are synthetic and generated by that script:
`Synthetic Paper.pdf` (6 pages, page n says "PAGE n") and `Synthetic Comic.cbz` (5 PNG pages; page n shows n white blocks on a
per-page colour). A second device is simulated with `scripts/t007/second_client.py`. No physical device.

## Locator policy used (see `LocatorPolicy`)

- **comic-page: canonical.** The locator is `{pageIndex, entryId, manifestVersion}` copied from the server's page manifest, the same shape
  `apps/web/src/reader/ComicReader.tsx` writes and resolves by entry id. No renderer interpretation is involved, so the profile
  question does not arise; observed in both directions above. Applies to CBZ/CBR/CB7.
- **foliate-cfi and pdf-page: device-local only.** These are renderer-defined; native/web round trips with both real renderers are not
  yet proven, so nothing is sent or applied (handoff F1). A native PDF write would only claim page granularity (x=0, y=0) and would
  not be allowed to overwrite a finer web position; that rule is not needed while PDF stays local.

## Limits of this evidence

- One synthetic CBZ and one synthetic text PDF on one emulator; not tested: CBR/CB7 (extraction is reported `incomplete`/unsupported by the
  server where applicable), rotated or cropped PDFs, large PDFs, password PDFs, RTL comics, zoom/pan behavior on the Litara path.
- Cross-device resume was shown for comics only, using an API script as the second device (not the web app in a browser).
- Page-image downloads are proven by unit tests (atomic publish, wrong-version rejection) and by this run; offline relaunch of a comic with
  cached pages was not exercised on the device.
- The reader header shows the edition label ("CBZ"/"PDF") instead of the book title; cosmetic, not fixed.
- No annotations, bookmarks or finish/unfinish from inside the PDF/comic reader.
