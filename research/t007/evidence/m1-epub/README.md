## What this does and does not prove

- Proven here: sign-in over bearer, paged `/titles` + `/editions`, `/editions/{id}/reader`, exact-version content download via the
  Range downloader, rendering in the preserved Foliate reader, local exact-file/version position, resume after process death.
- NOT proven / deliberately off: canonical server position sync. `LitaraRepository.nativeCompatibleProfiles` is empty, so the native
  CFI is never sent and a server CFI is never applied. See `handoffs/T007.md` finding F1.
- Not exercised: highlights, notes, bookmarks, finish/unfinish, conflicts, offline relaunch, account switch, PDF, comics.
